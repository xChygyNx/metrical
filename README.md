# metrical

Сервер сбора метрик и алертинга.


## Описание
Сервер запускается по адресу `http://localhost:8080`. Он по http принимает от агента POST запросы, в которых содержаться собранные им значения метрик компьютера на котором он запущен. Значения метрик сервер хранит в PostgreSQL/
На GET запросы вида `GET http://<АДРЕС_СЕРВЕРА>/value/<ТИП_МЕТРИКИ>/<ИМЯ_МЕТРИКИ>` сервер возвращал текущее значение метрики в текстовом видеtFu. При запросе неизвестной метрики сервис отвечает статусом `http.StatusNotFound`
По запросу `GET http://<АДРЕС_СЕРВЕРА>/` сервер отдает  HTML-страницу со списком имён и значений всех известных ему на текущий момент метрик.

## Кофигурирование
Параметры запуска могут задаваться переменными окружения, флагами в консоли при запуске сервера или агента или с помощью переменных окружения. Для сервера так же доступно подтягивание конфигурации из конфигурационного файла.

Приоритет источников для задания параметров сервера:
1) Переменные окружения.
2) Аргументы командной строки.
3) Файл конфигурации из параметра -c/-config или переменной окружения CONFIG.

Приоритет источников для задания параметров агента:
1) Переменные окружения.
2) Аргументы командной строки.

Переменные окружения использующиеся агентом:
`ADDRESS` отвечает за адрес эндпоинта HTTP-сервера.
`REPORT_INTERVAL` позволяет переопределять интервал времени с которым агент отправляет метрики на сервер.
`POLL_INTERVAL` позволяет переопределять интервал времени с которым агент собирает метрики.
`KEY=<КЛЮЧ>` ключ для подписи отправляемого сообщение

Переменные окружения использующиеся Сервера:
`ADDRESS` отвечает за адрес эндпоинта HTTP-сервера.[hfybn
`DATABASE_DSN` хранит строку с адресом подключения к БД
`KEY=<КЛЮЧ>`. При наличии ключа сервер проверяет совпадение вычисленного и полученного хеша

Консольные аргументы сервера:
Флаг `-a=<ЗНАЧЕНИЕ>` отвечает за адрес эндпоинта HTTP-сервера (по умолчанию localhost:8080).
Флаг `-d=<ЗНАЧЕНИЕ>` передпет строку с адресом подключения к БД
Флаг `-k=<КЛЮЧ>` активирует совпадения хешей для принимаемых запросов

Аргументы агента:
Флаг `-a=<ЗНАЧЕНИЕ>` отвечает за адрес эндпоинта HTTP-сервера (по умолчанию localhost:8080).
Флаг `-r=<ЗНАЧЕНИЕ>` позволяет переопределять частоту отправки метрик на сервер (по умолчанию 10 секунд).
Флаг `-p=<ЗНАЧЕНИЕ>` позволяет переопределять частоту опроса метрик из пакета runtime (по умолчанию 2 секунды).
Флаг `-k=<КЛЮЧ>` задает ключ для подписи сообщений

## Сжатие данных
Сервер и агент умеют обмениваться данными в формате gzip.
Сервер опционально принимать запросы в сжатом формате (при наличии соответствующего HTTP-заголовка `Content-Encoding`).
Отдавать сжатый ответ клиенту, который поддерживает обработку сжатых ответов (с HTTP-заголовком `Accept-Encoding`).

## Ошибки связи
Агент при ошибках передаче данных на сервер (ошибка при отправке запроса, ошибка с доступностью БД) использует пакет github.com/sethgrid/pester для повторной отправки метрик. Всего  осуществляется 3 попытки с увеличивающимся интервалом между ними

## Хэширование
Реализован механизм подписи и сверки передаваемых данных по алгоритму SHA256
Агент при включенном хэшировании передает вычисленный хэш сообщения в HTTP заголовке запроса `HashSHA256`. 
Сервер при наличие ключа на этапе формирования ответа на запрос делает то же самое. При несовпадении вычисленного хеша от сообщения и переданного в заголовке запроса в поле `HashSHA256` возвращает статус `http.StatusBadRequest`
